# Low-level abstract class for `bidsr`

Low-level abstract class definition; see
[`new_bids_class`](https://dipterix.org/bidsr/reference/new_bids_class.md)
to create new class definitions. All `bidsr` classes inherit this
abstract class, to provide consistent behavior.

## Usage

``` r
BIDSClassBase()
```

## Value

Do not call this `S7` class directly, see
[`new_bids_class`](https://dipterix.org/bidsr/reference/new_bids_class.md)
on how to use it properly
